# NePu Demo Video Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a ~45 s on-screen-narrated, music-reactive demo video of NePu (16:9 and 1:1) whose every number is read from the repo's built JSON.

**Architecture:** A standalone Remotion project in `video/`. `build-data.mjs` reads `site/public/data/*.json` and `data/proof.json` and emits `src/data.ts` plus `src/data.sources.json` (a pointer per value). Scenes take all figures from `data.ts` and all words from `copy.ts` (no digits except `$1`). A Higgsfield-generated track drives a pure `pulseFromSpectrum` function that animates glass cards and lines.

**Tech Stack:** Remotion (React, TypeScript), Node 24 `node:test`, Higgsfield CLI 1.2.2 (audio only). Use the `remotion:remotion-best-practices` skill for current Remotion and audio-visualization package/API names.

**Spec:** `docs/superpowers/specs/2026-11-04-nepu-demo-video-design.md`

## Global Constraints
- Every number on screen comes from `site/public/data/*.json` or `data/proof.json` via `data.ts`; none typed by hand (CLAUDE.md rule 1).
- No price predictions or targets (rule 7). All text in English (rule 8).
- Proof is shown with its network name (`testnet`) and the OpenTimestamps status exactly as `data/proof.json` records it.
- Narration is on-screen text; the video must read muted.
- Higgsfield output is the music track (and optionally text-free plates); no text or numbers inside AI images. Show `higgsfield generate cost` to the user and wait for approval before any generation.
- `video/` is not part of `make all`; the repo must still build offline from a clean clone. `video/out/`, `video/node_modules/` are gitignored.
- 30 fps, 1350 frames. Scene frame ranges: 0-150, 150-300, 300-540, 540-780, 780-990, 990-1200, 1200-1350.
- Outputs: `video/out/nepu-demo-16x9.mp4` (1920x1080), `video/out/nepu-demo-1x1.mp4` (1080x1080), `video/out/cover.png`.
- Commit messages `F7: <what>` with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commit steps run only after the user has okayed committing this work (ask once at Task 1). Leave the untracked `gcloud-login.sh` alone.

## Review Focus
1. A required JSON field missing or null: `build-data` must fail naming the field path, not render "NaN" (Task 1 test).
2. `distribution.periods.month` ends with an incomplete month: the card must use the last `complete: true` month (Task 1 test).
3. OpenTimestamps status changes from `pending` to a confirmed state: text derives from the file for both values, never hard-coded "pending" (Task 5 test).
4. A 64-char hash and a long contract name at 1:1: displayed truncated (`48c59060…b8c096`), never clipped, full value kept in data (Task 2 test + Task 7 frame check).
5. `valuation.json` scenario probabilities (`p_cr_ge_1`) are conditional model output that read as a forecast: they must not enter `data.ts` (Task 1 test). The Valuation card uses only `reverse.rows`.
6. Music shorter than 45 s: the audio check fails before render (Task 6 script).
