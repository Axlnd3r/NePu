# Methodology

Formulas, sources and limitations. Filled in from F3.

## Coverage ratio
CR = (buyback value + burn value) / gross issuance value, per day / 30d / 90d, in USD and in NEAR units.

## Break-even daily Intents volume
V* = (i * S * P - Burn_usd) / tau_eff, where i = annual inflation / 365, S = total supply,
P = NEAR price, tau_eff = protocol revenue / Intents volume.
